# MCP servers

This project registers two MCP servers so MCP-aware clients (Claude Code,
Cursor, VS Code 1.95+, Codex, etc.) can talk to the latest Astro ecosystem
without leaving the editor.

The server entries are configured in `.mcp.json` at the repo root.

## `astro` — official Astro build server

URL: `https://mcp.astro.build/`

Exposes tools for, among others:

- `search_astro_docs` — query the live Astro documentation
- `add_astro_integration` — add an integration to this project
- `upgrade_astro` — perform an in-place Astro upgrade
- `docs_astro` — open specific doc pages

## `astro-docs` — Astro docs search server

URL: `https://mcp.docs.astro.build/mcp` (streamable HTTP transport)

Source: <https://github.com/withastro/docs-mcp>

This is a read-only docs search server. It exists alongside `astro` so the
client has both a high-level build/orchestration tool (`astro`) and a
deep-dive docs lookup tool (`astro-docs`). When you're not sure which API
exists, prefer `astro-docs` to query the docs.

> [!NOTE]
> This server uses the new _streamable HTTP_ transport. Some clients
> (notably Windsurf as of July 2025) only support _SSE_ transport for
> remote servers, which is not compatible. If your client does not
> support streamable HTTP, swap the entry to use a local proxy:
>
> ```json
> {
>   "mcpServers": {
>     "astro-docs": {
>       "command": "npx",
>       "args": ["-y", "mcp-remote", "https://mcp.docs.astro.build/mcp"]
>     }
>   }
> }
> ```

## Clients

- **Claude Code**: reads `.mcp.json` automatically. You can also run
  `claude mcp add --transport http "Astro docs" https://mcp.docs.astro.build/mcp`.
- **Cursor**: reads `.mcp.json` automatically, or open
  `cursor://anysphere.cursor-deeplink/mcp/install?name=Astro%20docs&config=eyJ1cm...cCJ9`.
- **VS Code 1.95+ with GitHub Copilot Chat**: reads `.mcp.json` automatically.
- **Codex CLI**: add to `~/.codex/config.toml` under `[mcp_servers]`.
- **Older clients (stdio only)**: swap the entries to:
  ```json
  {
    "mcpServers": {
      "astro":      { "type": "stdio", "command": "npx", "args": ["-y", "@astrojs/mcp"] },
      "astro-docs": { "type": "stdio", "command": "npx", "args": ["-y", "mcp-remote", "https://mcp.docs.astro.build/mcp"] }
    }
  }
  ```

## Notes

- `.mcp.json` is project-scoped and checked into git on purpose so every
  contributor and every client pick up the same server config.
- Restart your client after editing this file so it re-reads the server list.
- The assistant running on this repo cannot itself reach these MCP
  servers — there is no `mcp__*` tool exposed in this session. The
  connection happens on YOUR side (the client) when it reads `.mcp.json`.
