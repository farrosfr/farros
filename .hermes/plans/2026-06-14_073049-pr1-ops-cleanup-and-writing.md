> **For Hermes:** Bite-sized tasks (2-5 min each), TDD where it makes
> sense, atomic commits. Use subagent-driven-development to dispatch
> a fresh subagent per task with two-stage review (spec compliance,
> then code quality).

**Goal:** Ship the first user-facing feature (the `/writing` page that
surfaces Substack content from farrosfr.com) on a clean foundation
(remove dead GitHub Pages workflow, dedupe lockfile, clean cf_monitor).

**Architecture:**
- `/writing` is a static page rendered at build time. RSS feed from
  `https://farrosfr.com/feed` is fetched once per build, parsed, and
  cached to `.data/writing-cache.json` with a 1-hour TTL.
- A hand-curated fallback (`src/data/writing.fallback.ts`) ensures the
  page renders even when the network is unavailable.
- The same uniform 3-col × 2-row pattern as the new Services grid.

**Tech stack (no new devDeps except `fast-xml-parser`):**
- Astro 6.3.3 (already in)
- UnoCSS (already in)
- fast-xml-parser (~50KB, zero deps)

**Defaults I'm shipping unless you object:**
- 1. Writing: RSS fetch (Option 2) with hand-curated fallback
- 2. Form v1: Web3Forms (deferred to a follow-up PR — not in this one)
- 3. Availability: static `hireable` field only (deferred to a follow-up)
- 4. Ops cleanup: in this PR, before the feature work

## Task 4: Create RSS fetcher with cache

**Objective:** Build-time fetch of `https://farrosfr.com/feed`, parse,
return latest N posts. Use a 1-hour disk cache and a fallback list.

**Files:**
- Create: `src/data/writing.ts`

**Step 1: Write the failing test (smoke test the fetcher)**

For now, manual verification (Astro pages don't have a unit test runner
configured). We'll do real verification in Task 6.

**Step 2: Write the fetcher**

```ts
import { readFileSync, writeFileSync, existsSync, mkdirSync } from 'node:fs';
import { dirname } from 'node:path';
import { XMLParser } from 'fast-xml-parser';
import { writingFallback } from './writing.fallback';

export type Post = {
  title: string;
  url: string;
  pubDate: string;
  description: string;
  source: string;
};

const FEED_URL = 'https://farrosfr.com/feed';
const CACHE_PATH = '.data/writing-cache.json';
const CACHE_TTL_MS = 60 * 60 * 1000; // 1 hour

type Cache = { fetchedAt: number; posts: Post[] };

function readCache(): Cache | null {
  if (!existsSync(CACHE_PATH)) return null;
  try {
    return JSON.parse(readFileSync(CACHE_PATH, 'utf-8'));
  } catch {
    return null;
  }
}

function writeCache(posts: Post[]): void {
  mkdirSync(dirname(CACHE_PATH), { recursive: true });
  const payload: Cache = { fetchedAt: Date.now(), posts };
  writeFileSync(CACHE_PATH, JSON.stringify(payload, null, 2));
}

function parseFeed(xml: string): Post[] {
  const parser = new XMLParser({
    ignoreAttributes: false,
    attributeNamePrefix: '@_',
  });
  const parsed = parser.parse(xml);
  // Substack Atom feed: feed.entry[]
  const entries = parsed?.feed?.entry;
  if (!Array.isArray(entries)) return [];
  return entries.slice(0, 20).map((entry: any) => ({
    title: String(entry.title?.['#text'] ?? entry.title ?? ''),
    url: String(entry.link?.['@_href'] ?? entry.link ?? ''),
    pubDate: String(entry.published ?? entry.updated ?? ''),
    description: String(entry.summary?.['#text'] ?? entry.summary ?? '')
      .replace(/<[^>]+>/g, '')
      .slice(0, 240),
    source: 'farrosfr.com',
  }));
}

export async function getLatestPosts(limit = 9): Promise<{
  posts: Post[];
  fromCache: boolean;
  fromFallback: boolean;
}> {
  const cache = readCache();
  if (cache && Date.now() - cache.fetchedAt < CACHE_TTL_MS) {
    return { posts: cache.posts.slice(0, limit), fromCache: true, fromFallback: false };
  }
  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 10_000);
    const res = await fetch(FEED_URL, { signal: controller.signal });
    clearTimeout(timeout);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const xml = await res.text();
    const posts = parseFeed(xml);
    if (posts.length === 0) throw new Error('Empty feed');
    writeCache(posts);
    return { posts: posts.slice(0, limit), fromCache: false, fromFallback: false };
  } catch (err) {
    console.warn(`[writing] feed fetch failed (${(err as Error).message}); using fallback`);
    if (cache) return { posts: cache.posts.slice(0, limit), fromCache: true, fromFallback: true };
    return { posts: writingFallback.slice(0, limit), fromCache: false, fromFallback: true };
  }
}
```

## Risks & Open Questions

1. **Cloudflare Pages build sandbox** — does it have network access
   to reach farrosfr.com? If not, the fallback list kicks in
   (intentional). We can verify after first deploy.
2. **Substack RSS schema** — Substack uses Atom, fields are stable
   since 2017. Risk: low. Mitigation: hand-curated fallback.
3. **bun.lock regen** — first `bun add` will rewrite bun.lock. This is
   expected; commit it.
4. **Search palette icon safelist** — `i-lucide-arrow-up-right` is
   used in the new card. If UnoCSS treeshakes it, the icon will be
   blank. Mitigation: add `'i-lucide-arrow-up-right'` to the safelist
   in `uno.config.ts` if the icon shows as missing.
5. **The 9 posts in the fallback** — I assumed 6-8 in the template.
   If you have time, paste 6 real Substack URLs into
   `writing.fallback.ts`; otherwise 2-3 are enough to ship.
